# Malie Tool

A Rust command-line tool for inspecting, extracting, packing and repacking Malie Engine game archives and EXEC scripts.

A Malie archive unpacker and repacker for Windows intended for localization and modding workflows.

## Features

- Inspect, list, unpack, pack and verify archives
- Support for LIB, LIBP and LIBU archive formats
- Extract and rebuild game resources
- Export and import EXEC script text as UTF-8 JSON
- Interactive terminal wizard for common workflows
- Windows x64 release
